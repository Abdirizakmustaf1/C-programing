# Week 1 — Introduction to Visual C#

## Topics
- Objects, properties, methods, and classes
- Controls: Label, TextBox, and Button
- Visual Studio and the IDE
- Toolbox and Properties Window
- Projects, solutions, and source-code files
- Naming rules for controls

## Form design
This Form demonstrates a simple GUI with a title Label, a student-name Label, a TextBox, a Button, and a result Label.

## Run
Open `Week1.csproj` in Visual Studio on Windows and run the project. The form is created in `Form1.cs`, so a separate Designer file is not required.
