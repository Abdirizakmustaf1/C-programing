- Label and TextBox controls
- IntelliSense
- Comments, blank lines, and indentation
- Sequential execution of statements
- Closing a form with `this.Close()`

## Form design
This Form includes Labels, a TextBox, and Show Message, Clear, and Exit buttons.

## What the buttons do
- **Show Message:** checks the name, updates the output Label, and displays a MessageBox.
- **Clear:** clears the TextBox and resets the output Label.
- **Exit:** closes the current form.

## Run
Open `Week2.csproj` in Visual Studio on Windows and run the project. The form is created in `Form1.cs`, so a separate Designer file is not required.
