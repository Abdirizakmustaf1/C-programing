# Week 5 – Student Information System

## Project Description
This project is a Student Information System developed using C# Windows Forms.
It allows users to enter student information, display saved records, and count
the total number of students.

## Form Controls
- Label: Displays field names and the total student count.
- TextBox: Accepts Name, Age, and City.
- Save Button: Adds student information to the RichTextBox.
- Clear Button: Clears the input fields.
- RichTextBox: Displays saved student records.

## Main Features
1. Enter student Name, Age, and City.
2. Validate that all fields are completed.
3. Validate that Age is a non-negative whole number.
4. Save and display student records.
5. Automatically update the total student count.
6. Clear the input fields.

## Technologies Used
- C#
- Windows Forms
- Visual Studio
- .NET

## How to Run
1. Create a Windows Forms App project in Visual Studio.
2. Use `Week5` as the namespace, or change the namespace in both code files
   to match your project.
3. Replace the form code with `Form1.cs`.
4. Use the supplied `Program.cs` as the startup code.
5. Press F5 to run the application.

## Conclusion
This project demonstrates Windows Forms controls, button click events,
input validation, RichTextBox output, and counting student records in C#.
